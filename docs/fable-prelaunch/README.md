# Fable pre-launch pack

Hand this folder to Fable (or any design model with vision) for a last pass before chrcit.com launches.

## What to do

1. Open a new Fable chat.
2. Recapture the site from a production `astro preview` of `site/` (no Astro dev toolbar) if you need images. The original `screenshots/` set was removed after the audit.
3. Paste the entire contents of `PROMPT.md` as the message.

## What this pack is

A design-critique brief, not a rebuild brief. Direction is locked (DITHER: light paper, Inter Tight only, riso red, sharp tiles). The ask is: what to change so the whole site is better at launch.

## Files

| File | Purpose |
| --- | --- |
| `PROMPT.md` | Paste this. Standalone; Fable does not need the rest of the repo. |
| `SCREENSHOTS.md` | Former caption list. Captures are no longer in the repo. |
