# Fable pre-launch pack

Hand this folder to Fable (or any design model with vision) for a last pass before chrcit.com launches.

## What to do

1. Open a new Fable chat.
2. Attach the images in `screenshots/` **in filename order** (`01-` through `20-`).
3. Paste the entire contents of `PROMPT.md` as the message.
4. Send as one turn. Do not drip-feed screenshots after the prompt.

If the tool caps attachments, attach at least these eight, still in filename order:

1. `01-home-desktop.png`
2. `02-home-desktop-full.png`
3. `04-home-desktop-role-open.png`
4. `06-home-mobile-full.png`
5. `08-article-desktop-hero.png`
6. `09-article-desktop-reading.png`
7. `14-books-desktop.png`
8. `17-uses-desktop-stack.png`

Then, if you have slots left, attach `11`, `16`, `19`, `20` (article mobile, uses gear, colophon, 404). The prompt already describes every page.

## What this pack is

A design-critique brief, not a rebuild brief. Direction is locked (DITHER: light paper, Inter Tight only, riso red, sharp tiles). The ask is: what to change so the whole site is better at launch.

Screenshots were captured from a production `astro preview` of `site/` (no Astro dev toolbar) at 1440×900 desktop and 390×844 mobile, 2× pixel density, 2026-08-27.

| File | Purpose |
| --- | --- |
