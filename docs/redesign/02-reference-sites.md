# Reference sites — the family chrcit.com should rhyme with

Analysis from live HTML/CSS (2026-08-25). All three are dark-base sites with one loud accent, strong type opinions, and copy that refuses corporate tone.

## madebyarthouse.com — the professional pole

- Background `#11110f` (warm near-black), foreground `#f2eee6` (cream), accent electric blue `#0011ff`, muted `#a7a39a`.
- Type: ABC Whyte Inktrap (serious contemporary grotesque) + monospace accents. Logo color studies (multi-color variants) baked into CSS.
- Structure: numbered service sections (01 Strategy, 02 Software …), crew list with roles, client list, network list. Story-scroll homepage with blue full-bleed sections.
- Voice: confident, plain, editorial. "Arthouse is a creative engineering studio." No hype words.
- Vibe words: restrained, warm-dark, editorial, craft-signaling, Viennese studio.

## hausgemacht.org — the emotional pole

- Palette: darker grey `#161616`, dark grey `#303030`, light grey `#e6e6e6`, neon green `#00fca4`, pink `#ff0069`, violet `#6932ff`.
- Type: PP Monument Extended (very wide display caps) + Archivo/Sora/Kanit.
- Voice: German, intimate, cheeky, values-first ("Wie dein Crush in den DM's", newsletter = "Intime Liebesbriefe", "6969 Zauberwesen sind schon dabei"). Feminist techno collective, SafeR spaces, community.
- Vibe words: rave, neon-on-dark, warm-hearted, loud, utopian.

## rebased.wtf — the irreverent pole

- Type: DxDynamix (techy display, also the logo) + Outfit body. Accents purple `#a855f7`, cyan `#22d3ee`.
- Structure: zine/brutalist — numbered sections (01 THE TALKS…), uppercase marquees ("TALKS●DRINKS●CURIOUS MINDS●NO BORING STUFF●"), monospace-adjacent labels, joke crew titles ("chief vibe officer").
- Voice: anti-corporate, funny, sincere underneath ("WE'RE BUILDING A SPACE WHERE TECH FEELS HUMAN AGAIN").
- Vibe words: zine, playful-brutalist, meetup-punk, tongue-in-cheek.

## Shared DNA across all three

1. Dark base + one saturated signature accent (blue / neon green+pink / purple+cyan).
2. One opinionated display face doing identity work, quiet functional body type, mono for labels/metadata.
3. Numbered sections and index/archive structures — editorial systems, not marketing layouts.
4. Copy with a human pulse: direct, no filler, jokes allowed, values visible.
5. Vienna, community, craft.

## Implication for chrcit.com

The personal site is the fourth corner of this map: it should feel like the person who is simultaneously the strategist at Arthouse, the systems-builder at hausgemacht, and the vibe officer at rebased — without copying any single site's costume. Open question: where it sits between the professional pole and the playful poles. See `03-essence-and-vibe.md`.
